# 使用說明 — Pokémon Champion 隊伍模擬器 V1.7

本 App 完全離線可用。所有資料（Pokémon、招式、特性、道具、Regulation）已內置；有網絡時可以更新。

## 1. 安裝及更新 App

1. 打開 GitHub repository 的 **Releases**，下載最新 `PokemonChampions-v1.6.x.apk`。
2. 安裝時允許「安裝未知來源的應用程式」。
3. 之後的版本可直接覆蓋安裝，隊伍及設定會保留（每個 APK 都用同一條 key 簽署）。

## 2. 主頁

- **資料狀態**：資料版本、目前 Regulation、在線／離線、最後更新時間。
- 如有新資料，主頁會顯示「有可用資料更新 → 查看」。
- 如新 Regulation 已開始但未有 Pokémon 名單（例如 12 月 2 日 M-D 剛開始時），會顯示提示，App 會繼續用暫定名單。

## 3. 資料更新

| 方法 | 做法 |
|---|---|
| 線上更新 | 資料更新 → **立即檢查更新** → **下載並預覽更新** → 確認 |
| 自動更新 | 資料更新 → 自動更新：關閉／自動檢查並提示（預設）／自動下載並套用 |
| 匯入檔案 | 資料更新 → **選擇資料檔並匯入**（`.json` 或 `.zip`） |
| 還原 | 資料更新 → 還原上一版本／改回內置資料 |

- 每天 03:00（香港時間）GitHub 會由 Pokémon Showdown 重新產生資料；有改變才會發佈。
- 下載的資料會先核對 SHA-256 及資料格式，不通過就不會套用，原有資料不變。
- 套用前會列出 Change Log（新增／移除的 Pokémon、招式、Regulation 名單等）。
- 套用後會列出**受影響的隊伍**（例如某 Pokémon 不能在新名單使用）。舊隊伍一律保留。
- 資料檔包含所有 Regulation，所以「下載所選 Regulation」與「下載全部」相同，每次都是完整下載（約 800 KB）。

## 4. Regulation

- Regulation 頁列出 M-A 至 M-D：狀態（目前／即將／歷史）、日期、規則及可用 Pokémon。
- 「套用到 App」會讓圖鑑、Speed Tier 等使用該 Regulation；選「自動」會跟隨目前 Regulation。
- M-D 在官方名單公開前為**暫定**（M-C 全部 ＋ 官方已公布的 Heatran、Dondozo、Tatsugiri 及其 Mega），會標示「暫定」。

## 5. Team Builder

1. Team Builder → **建立新隊伍**（或 **匯入**：貼上 Showdown／PokePaste 文字）。
2. 點空位選 Pokémon；再點隊員設定特性、道具、性格、Stat Points（總數 66、每項最多 32）及 4 個招式。
3. **Mega**：選 Mega 形態會自動裝備 Mega Stone，屬性、特性、能力值即時更新，所有分析亦同步。
4. **合法性檢查**：合法／不合法／待驗證／未完成，逐項列出原因。
5. **隊伍碼**：可記錄遊戲內的 10 位隊伍 ID（只作記錄；App 不能用隊伍碼讀取隊伍）。
6. 隊伍仍使用已結束的 Regulation 時，隊伍頁頂會提示，可一按改用目前 Regulation。
7. 「對手」分頁可建立或匯入對手隊伍，用於 Matchup 及對戰模擬。

## 6. 分析工具（在隊伍頁）

| 工具 | 內容 |
|---|---|
| 隊伍分析 | 總覽、Coverage Matrix、防守矩陣、攻擊覆蓋、配合、報告及改善方向 |
| Speed Tier | Regulation 全部 Pokémon 的速度排位及我方位置；順風、戲法空間、圍巾等條件 |
| 速度線 | 每隻 Pokémon 的極速、圍巾、+1、+2、順風、速度特性 ×2 等速度；選隊員或輸入數值，綠＝先手、橙＝同速、紅＝後手 |
| Matchup 研究 | 對手隊伍或自選 Pokémon；威脅、應對、速度比較、先發建議 |
| 傷害計算 | 傷害範圍、16 個隨機數、KO 機率、生存分析；基本／進階模式 |
| 對戰模擬 | 單一回合、多回合、情境測試；第一回合 ×200、完整對戰 ×100 |

所有建議都標示為「分析建議」，並列出計算依據。模擬勝率為雙方 AI 的估算，不代表實際對戰結果。

## 7. 資料可靠程度

| 標示 | 意思 |
|---|---|
| 官方確認 | 官方公布 |
| 已驗證 | 已與遊戲或其他來源核對 |
| 社群資料 | Pokémon Showdown champions mod（以遊戲 data dump 為基礎） |
| 待驗證 | 暫定資料，例如未公開名單的 M-D |

## 8. 常見問題

- **離線可以用嗎？** 可以，全部功能都可離線使用；只有「檢查更新」需要網絡。
- **12 月 2 日要做甚麼？** 開啟 App（有網絡）會自動檢查。Showdown 一般在新 Regulation 開始後一至數天更新，之後 App 會提示可更新。
- **更新後出問題？** 資料更新 → 還原上一版本。
